Daily close (Kassenabschluss) — code map
Generated from the MeDoc tree on 2026-11-16.

This is the cash closing: counted cash, expected cash, a numbered Kassenbericht (TB-…), and an immutable protocol row. It is not the appointment calendar. `deriveDayClosedSpans` in appointment-calendar-layout.ts only marks hours the practice is shut. That name is unrelated.

`apps/practice-host-ui/src/lib` is a symlink to `packages/shared/src/lib`. Those paths are one copy.

There is no LAN HTTP route for day close. The screen talks to the desktop process by Tauri command names.
