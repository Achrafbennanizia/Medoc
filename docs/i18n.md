# MeDoc UI internationalization

## Overview

User-visible strings live in **JSON locale catalogs** under `packages/shared/locales/`:

| File | Language |
|------|----------|
| `de.json` | German (default) |
| `en.json` | English |
| `fr.json` | French |
| `ar.json` | Arabic (RTL) |

Runtime: **i18next** via `packages/shared/src/lib/i18n.ts` (Zustand locale store, `medoc-locale` persist key).

## Adding a string

1. Pick an English key id, e.g. `page.termine.title`.
2. Add the same key to **all four** JSON files with translated values.
3. Use in React:

```tsx
import { useT, useTParams, useDateFnsLocale } from "@/lib/i18n";

const t = useT();
const tp = useTParams();
const dateFnsLocale = useDateFnsLocale();

<CardHeader title={t("page.termine.title")} />
toast(tp("page.patient.saved", { name }), "success");
format(date, "PPP", { locale: dateFnsLocale });
```

4. Run `npm run i18n:verify` — must report identical key counts.

### Key naming

| Prefix | Use |
|--------|-----|
| `nav.*` | Sidebar / navigation |
| `common.*` | Save, Cancel, Loading |
| `page.{feature}.*` | Page copy |
| `palette.cmd.*` | Command palette entries |
| `breadcrumb.*` | Breadcrumb segments |
| `error.*` | Backend validation codes + client errors |
| `a11y.*` | aria-labels |
| `enum.*` | Domain enum display labels |

## RTL (Arabic)

- `app-layout.tsx` sets `document.documentElement.dir` and `lang` when locale is `ar`.
- `html[data-arabic-font="1"]` applies an Arabic-friendly font stack (`index.css`).
- Prefer **logical CSS** (`margin-inline-start`, `text-align: start`) in new components.
- Existing RTL overrides: `[dir="rtl"]` rules in `apps/practice-host-ui/src/index.css`.

## Backend errors

Rust commands should return stable codes:

```rust
return Err(AppError::validation_code("error.work_time.no_open_session"));
```

The UI maps codes via `formatIpcError()` in `packages/shared/src/lib/ipc-errors.ts` (also used by `errorMessage()` in `utils.ts`).

Add matching `error.*` keys in all four locale JSON files.

## CI / scripts

| Command | Purpose |
|---------|---------|
| `npm run i18n:verify` | 4-way key parity + Arabic critical-key check |
| `npm run i18n:scan` | Detect new hardcoded German in TSX (baseline-aware) |
| `npm run i18n:extract` | Regenerate JSON from legacy TS dict (maintenance) |

Tests: `packages/shared/src/lib/i18n-locales.test.ts`

## Locale switching

Users change language under **Einstellungen → Darstellung**. `useLocale().setLocale("en" | "de" | "fr" | "ar")` syncs i18next.
