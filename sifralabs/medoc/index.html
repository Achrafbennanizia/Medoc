One family of practice programs

MeDoc is the name of the practice programs we make. They are built the same way, on the same foundations, by the same people.

  1. One secure coreEncryption, roles, the audit log, sync, licences and backups are built once and shared by every MeDoc program.
  2. One teamThe people who write MeDoc are the people who install it with you, train you and answer your questions.
  3. Built for each specialtyEach program is made for one specialty, with the records, documents and daily routine it needs. Dentists come first.
  4. Sold only when readyWe sell a MeDoc program only when it is ready for a real practice. Until then it stays in development, and we announce no dates.
