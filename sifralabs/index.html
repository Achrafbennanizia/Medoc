02

Four principles, each with evidence

A principle is only worth stating if the code proves it.

  1. Data stays where it is created

    Patient records live on the practice's computers, not on our servers. The practice keeps working when the internet does not.

    Encrypted SQLCipher database · offline by default

  2. Every access leaves a trace

    Reception cannot open the medical chart. When a clinician does, it is recorded in a log that cannot be edited quietly.

    Permissions checked in the core · HMAC-chained audit log

  3. Built to be maintained

    Small, regular releases. Mistakes fixed in the open. A product meant to be supported for ten years.

    Incremental delivery · V-model documentation

  4. Clear to the people who use it

    The receptionist at 8:30 and the dentist between patients should never have to think about the software.

    Usability engineering · four languages, incl. right-to-left Arabic
